Resumen técnico

Banco UMG contempla una arquitectura de alta disponibilidad mediante Failover Cluster, respaldos automatizados en una ubicación externa y objetivos de recuperación definidos mediante RPO y RTO.

  • Alta Disponibilidad: si el servidor principal falla, otro nodo puede tomar el servicio.
  • Backup en Cloud: permite conservar respaldos fuera del servidor principal.
  • RPO: define cuánta información se podría perder como máximo.
  • RTO: define cuánto tiempo puede tardar la recuperación del servicio.
